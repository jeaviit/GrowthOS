## Design Principles
- Mobile-first, responsive layout
- Fast load times — minimize heavy dependencies
- Clean, professional aesthetic suited for an agency
- Strong calls-to-action and clear value proposition above the fold

## Key Sections (Planned)
- Hero — headline, subheadline, primary CTA
- Services / What We Do
- Work / Portfolio / Case Studies
- About / Team
- Testimonials / Social Proof
- Contact / CTA footer

## Coding Conventions
- No comments unless the why is non-obvious
- Prefer semantic HTML elements
- CSS custom properties (variables) for colors, spacing, typography
- Keep components small and focused

## Copy & Content
- Tone: confident, clear, professional — no filler phrases
- All placeholder copy should be marked with `<!-- TODO: replace -->` so it's easy to find

## Assets
- Images go in `assets/images/`
- Icons go in `assets/icons/`
- Fonts go in `assets/fonts/` (or loaded via CDN)
